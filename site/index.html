1.1. Hızlı Kurulum (3 Yol — Rust Derleyicisi Şart Değil)

Host makinede Rust veya Python kurulu olmadan, non-root UID 10001, salt-okunur dosya sistemi ve sıfır ağ erişimiyle doğrudan GHCR'den çalıştırın (herkese açık, docker login gerekmez):

bash / powershell · ghcr.io/imza464-cmyk/citadel-math:0.2.0 
docker run -i --rm \
  --read-only \
  --tmpfs /tmp:size=64M,noexec,nosuid \
  --cap-drop=ALL \
  --security-opt=no-new-privileges:true \
  --pids-limit=128 \
  --memory=512m \
  --network=none \
  ghcr.io/imza464-cmyk/citadel-math:0.2.0

1) GitHub Releases v0.2.0 sayfasından platform ikilisini (citadel_math_core-windows-x86_64.exe veya citadel_math_core-linux-x86_64) indirip PATH'e (veya KMATH_RUST_BIN değişkenine) koyun.
2) Wheel paketini tek komutla kurun (database/, data/ ve AGENTS.md wheel içine gömülüdür):

pip · doğrudan v0.2.0 wheel kurulumu 
pip install https://github.com/imza464-cmyk/citadel-math/releases/download/v0.2.0/kmath_mcp-0.2.0-py3-none-any.whl
kmath stats

Katkıcılar ve yerel geliştirme için kaynaktan derleme ve tüm 26 kapı + güvenlik test paketi:

1.4. Kapsam ve Bilinen Sınırlar

  • Konumlandırma: LLM destekli mühendislik akışlarında birim, payda tekilliği ve yuvarlama hatası yakalayan deterministik yardımcı doğrulama katmanıdır. SymPy, SciPy, nalgebra, uom, GMAT veya sertifikalı 3B FEA/CFD yazılımlarının yerini alma iddiası taşımaz.
  • Cebirsel Eşdeğerlik (PolyZ / MultiPolyZ): Taşma korumalı checked_i64 tamsayı polinom halkasında çalışır; Lean veya Coq gibi genel bir teorem ispatlayıcı değildir.
  • Yörünge ve Yapısal Analiz: 2B noktasal kütle RK4/RK4(5), 7 katmanlı USSA-1976, WGS84 J2 / Lambert ve NASA SP-8007 kavramsal ön-boyutlandırma (Phase-A) filtresidir; 6-DoF CFD veya tam N-cisim JPL efemeris çözücüsü değildir.

8.3. Sorun Giderme (resolve_rust_bin() & rc=127)

Her Rust destekli MCP aracı derlenmiş çekirdek ikilisini şu deterministik 5 adımlı öncelik sırasıyla arar ve mutlak yola (os.path.abspath) çevirir:

  1. KMATH_RUST_BIN ortam değişkeni (tanımlıysa tek yetkili geçersiz kılmadır; dosya yoksa sessizce başka ikiliye düşmez, rc=127 döner).
  2. <repo>/citadel_math_core/target/release/citadel_math_core(.exe)
  3. <repo>/citadel_math_core/target/debug/citadel_math_core(.exe)
  4. <repo>/bin/citadel_math_core(.exe)
  5. Sistem PATH'i (citadel_math_core, citadel_math_core-windows-x86_64.exe, citadel_math_core-linux-x86_64).
İkili Eksikse Ne Olur? Saf Python araçları (kmath_dimension_check, kmath_constant, kmath_materials, kmath_simulate_trajectory) çalışmaya devam eder; Rust destekli araçlar aranan tüm yolları, cargo build --release komutunu ve GitHub Releases + KMATH_RUST_BIN çözümünü içeren yapısal JSON hata (rc=127) döndürür.
